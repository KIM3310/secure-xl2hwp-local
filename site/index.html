Spreadsheet automation for secure local environments.

This public Pages site is documentation only. The actual service is intentionally designed for local secure processing, not public web runtime. That is the product decision, not a deployment gap.

Core capabilities

  • SpecKit-driven contracts, profiles, and template mapping.
  • CoT-style spreadsheet normalization and document mapping pipeline.
  • JWT auth, audit logging, signing, and readiness checks.
  • Offline installation and regulated handoff posture.

Why this stays local

  • Source spreadsheets and generated artifacts may be regulated or sensitive.
  • Trust boundary matters more than public demo convenience.
  • The strongest portfolio signal here is deployment restraint, not public hosting.
