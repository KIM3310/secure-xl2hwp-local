# Monetization Playbook - secure-xl2hwp-local

This file is a commercial planning artifact, not a guarantee of revenue. Use it to make the repository legible as a sellable product, pilot, workshop, license, or proof-of-value package.

## Commercial Lane

- **Lane:** B2B local document automation
- **Primary buyer:** Korean back-office, public-sector-adjacent, legal/admin, and secure internal workflow teams.
- **Revenue wedge:** Air-gapped/local Excel-to-Hancom conversion with audit logging and signed exports.

## Offer Ladder

1. **Offline license** - pricing hypothesis: $499-$2k/seat/year
2. **Controlled workflow setup** - pricing hypothesis: $5k-$25k setup
3. **Template migration package** - pricing hypothesis: $1k-$6k/month template support

## Acquisition Channels

- Korean admin workflow demos
- Offline-security messaging
- Hancom automation examples

## Proof Gates Before Selling

- make verify passes
- Sample signed export works
- Auth setup is explicit

## Risk Boundaries

- Approved templates required
- Workstation policy needed
- Retention/signing keys customer-specific

## 30/60/90 Day GTM

- **30 days:** Create 3 template demos
- **60 days:** Build local install guide
- **90 days:** Offer offline pilot

## Metrics That Matter

- Document processing time
- Template drift detection
- Signed export verification

## Positioning Note

Lead with the specific operational pain, then show the runnable proof, then offer a narrow pilot. Do not pitch the repository as a vague app; pitch it as a concrete workflow with evidence, risk boundaries, and a next buying step.
